## Overview
Parsing and statistical analysis of chess match datasets (PGN format) utilizing Python and Regular Expressions (RegEx) to extract game states, moves, and outcomes.

## Files
- `my_re_functions.py`: Core regular expression parsing functions.
- `test_my_re_functions.py`: Unit tests for the RegEx functions.
- `erotima_1.py` / `erotima_2.py`: Execution scripts for data extraction.
- `WorldChamp2023.pgn` / `RetiKIA.zip`: Chess match datasets.

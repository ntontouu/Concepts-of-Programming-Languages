## 🔍 Overview
This assignment shifts the paradigm from sequential scripting to event-driven execution. The application implements an interactive window where visual elements (colors) change dynamically in response to user inputs (clicks, key presses) and internal timers.

---

## 📐 Theoretical Background
In event-driven programming, the flow of the program is determined by external events.
- **Main Loop:** The application runs an infinite loop waiting for events.
- **Event Handlers/Callbacks:** Functions that trigger asynchronously when specific actions occur.
- **State Management:** Tracking the RGB color values and dynamically updating the UI components without blocking the main execution thread.

## Overview
Implementation of a Cartesian coordinate system management script in Python. The project handles reading points from text files, processing them, and executing coordinate-based calculations.

## Files
- `erotima2.py`: Main execution script.
- `utils.py`: Helper functions for coordinate processing.
- `points.txt` / `mypoints.txt`: Datasets containing coordinate points.

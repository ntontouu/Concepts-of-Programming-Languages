## Overview
A comparative study of programming paradigms (Imperative/Object-Oriented vs. Functional). The project benchmarks the execution and logic of sorting multi-dimensional points in Python and Haskell across scaling datasets.

## Files
- **Haskell Implementation:** `haskell_sketo.hs`
- **Python Implementations:** `python_sketo.py`, `python_metrio.py`
- **Datasets:** Scaled input files (`input1000.txt`, `input10000.txt`, `input100000.txt`, `input1000000.zip`).
